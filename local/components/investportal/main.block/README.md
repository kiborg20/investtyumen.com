Компонент для блоков страниц "О регионе".

Так как "О регионе" является набором шаблонных страниц, для них подготовлен единый шаблон в компоненте creative.foundation - o-regione, в котором подключается компонент oregione.block и oregione.intro.

Основная задумка заключается в том, что в инфоблоках с информацией на этих страницах должен быть раздел с символьным кодом, соответствующим коду страницы.
В случае отсутствия раздела текущей страницы, блок пропускается.
